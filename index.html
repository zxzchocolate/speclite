SPECLITE
TEXT-BASED IMAGE EXPERIMENT · v0.1
A tiny image format you can read

Images, written as text.

Speclite stores an image as rows of symbols and a hexadecimal color palette. Convert an image into a UTF-8 .speclite file, open an existing one, preview it, or export it as PNG. Everything runs locally in your browser.

Conversion preserves the original pixel dimensions by default. Set maximum width to a positive number to downscale large images. Palette conversion still reduces colors, so more palette colors preserve detail but make the text file larger.

02 / Speclite source

Format v1: one character per pixel, rows under PIXELS, then SYMBOL:RRGGBB entries under COLORS. UTF-8 text, no external libraries.

Format example

SPECLITE/1
WIDTH 3
HEIGHT 3
PIXELS
ABC
CBA
ABC
COLORS
A:FFFFFF
B:000000
C:FF0000
END

Speclite v0.1 is an experimental text format, not yet a replacement for compressed formats like JPEG, WebP, or AVIF. Files can be larger than binary images; compactness depends on image content and palette size.
